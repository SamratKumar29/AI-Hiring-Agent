Goals of AI-Hiring-Agent:

Unified UI which:
1. Takes my resume or CV.md file, ask few of my preferences(including base salary requirements) and understand my profile. Keep this saved in a profile, user can later load this profile, edit, delete or create a new one.
2. I provide all the job posting websites, links. Ex: LinkedIn, Michael page, multi recruit, indeed, naukri, wellfound, remoteOK etc., It could even be individual job posting links directly from company website or a PDF file containing these links.
3. Now the tool will use local Kurt-Chan/ai-job-scraper online on schedule, anandanair/job-scraper locally when I hit start and finds all jobs I am eligible for.
4. These jobs are fed into santifer/career-ops and it generates a list which ranks them based on my preferences, suitability and chances of cracking it.
5. I can check out the original postings for each and if I like it I can generate a tailored CV using srbhr/resume-matcher or use the built in career-ops resume maker.
6. Once Resume is created and I apply, the remaining career-ops features should be offered such as cover letter preparation, interview prep etc., from which I can choose and go through it.
